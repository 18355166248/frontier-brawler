# Frontier Brawler 0.1.0

首个可持续游玩的 Web 原型版本。目标平台是桌面浏览器与手机横屏浏览器，技术栈为
Vite、TypeScript 和 Canvas 2D。

## 已包含

- 六关 DNF 式房间推进、小地图、奖励房与分阶段首领；最终关后可保留装备和基地
  进度开启新一轮。
- 重击、疾锋、术法三职业，12 件装备及职业动作覆盖链。
- 五栋基地建筑、战斗资源产出、建造队列、离线收益与版本化本地存档。
- 键盘与手机横屏多指触控、暂停/后台自动暂停、Web Audio 事件音效。
- 首次流程情境引导；第一关首领使用独立教学招式组，后续首领保持完整难度。
- 角色、六类敌人、装备和建筑正式美术，以及素材加载失败兜底。

## 已知边界

- 这是纯静态 Web 构建，本地存档只保存在当前浏览器，不提供账号或跨设备同步。
- 少数职业扩展动作仍复用现有动作行并叠加程序化特效，尚无逐动作专属角色帧。
- M6 的循环转化和 50 单位中端安卓性能仍保留为长期观测项，不阻塞本版本。

## 发布验证

```bash
npm ci
npm run validate
```

通过后将 `dist/` 整体部署到任意静态托管目录即可；资源路径为相对路径，支持站点子目录。
