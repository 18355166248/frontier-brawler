# 五种敌人剪影验证（2026-08-25）

## 结论

阵容概念通过 96px 纯黑剪影验收，可以进入动作表制作：

1. `grunt`：中型、短刀、均衡站姿。
2. `shield`：宽体、巨型塔盾主导轮廓。
3. `ranged`：最高最瘦、尖兜帽、长弓和箭袋。
4. `charger`：最低重心、前倾楔形、单侧撞角肩甲。
5. `elite`：体型最大、双角重甲、双手巨锤。

纯黑状态下五者仍能通过高度、宽度、重心、头型和武器区分，不依赖颜色或材质。
