# 基地建筑 AI 样板（2026-08-27）

本轮先验证静态建筑管线，演武场为第一栋样板。源图严格使用 2×2：未建成 / 建造中 /
建成 / 图标。内置生图当前会把透明棋盘烘进 RGB，因此正式流程改用单色洋红背景，
再做确定性色键和触格检查；建筑设计本身仍由图片模型生成。

## 演武场提示词摘要

- 低多边形卡通 3D，正交 3/4 视角（约 62° 方位角）
- 四格使用同一相机、缩放、基线、占地轮廓和设计语言
- 深色旧木、暖土、暗红布、少量灰青金属；无人物、文字、标志和场景背景
- 2×2 阅读顺序：空地基与整齐木料 / 竹脚手架施工 / 木质练武亭与木人桩 / 简化图标
- 背景必须是均匀洋红色键，不直接依赖模型输出 alpha

## 构建

```bash
python3 tools/build_building_atlas.py \
  docs/experiments/base-buildings-2026-08-27/training-ground-grid.png \
  -o public/art/buildings/training-ground-v1.png
```

脚本会拒绝非严格二等分、空格或可见内容触格的网格。进入游戏后仍需人工检查基地卡片
上的缩放、可读性以及未建成 → 施工 → 建成三态是否能一眼区分。开发预览可直接打开：

- `?base=unbuilt`
- `?base=building`
- `?base=completed`
