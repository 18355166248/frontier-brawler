# 基地建筑 AI 样板（2026-08-27）

本轮完成演武场、锻造台、丹房、资源田、藏经阁五栋静态建筑。每张源图严格使用
2×2：未建成 / 建造中 / 建成 / 图标。内置生图当前会把透明棋盘烘进 RGB，因此
正式流程改用单色洋红背景，再做确定性色键和触格检查；建筑设计本身仍由图片模型生成。
源图保留四格，运行时图集只打包实际使用的前三态，每格降采样到 192×192；图片在首次
打开基地时才加载，不与战斗首屏素材争抢带宽。

## 共用提示词规格

- 低多边形卡通 3D，正交 3/4 视角（约 62° 方位角）
- 四格使用同一相机、缩放、基线、占地轮廓和设计语言
- 深色旧木、暖土、暗红布、少量灰青金属；无人物、文字、标志和场景背景
- 2×2 阅读顺序：未建成地基 / 脚手架施工 / 完整建筑 / 简化图标
- 背景必须是均匀洋红色键，不直接依赖模型输出 alpha
- 饱和紫色 / 品红色会与色键软过渡带冲突，禁止用于建筑主体和装饰
- 演武场以木人桩和开放练武亭为剪影；锻造台以低矮石炉、短烟囱和铁砧为剪影
- 丹房以圆形大丹炉和弧形屋顶为剪影；资源田以两排苗床和架高粮仓为剪影
- 藏经阁以陡峭双层屋脊、卷轴架和阅读台为剪影

## 构建

```bash
npm run build:building-art
```

脚本会清理主体外的小碎片，把三个运行态注册到统一底线，并拒绝非严格二等分、空格、
安全边距不足或底线不一致的图集。进入游戏后仍需人工检查基地卡片上的缩放、可读性以及
未建成 → 施工 → 建成三态是否能一眼区分。开发预览可直接打开：

- `?base=unbuilt`
- `?base=building`
- `?base=completed`
