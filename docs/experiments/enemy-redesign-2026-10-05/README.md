# 普通怪重设计 · 第一版样板

当前 Godot 普通怪仍由 illustrated_actor.gd 绘制，Boss 已由 copper_guard_visual.gd 使用独立素材包。
本轮优先重做普通刀卒，与主角、铜面守卫及雾林的绘制精度统一。

## 视觉契约

- 身份：雾蚀刀卒，受雾侵蚀的山门旧军；瘦长成人比例，避免与重甲 Boss 混淆。
- 主轮廓：破铜半面、单侧肩甲、残布腰裙、分开的双腿、前向弯刀。
- 色彩：炭黑衣料、旧铜、锈棕残布、灰白裂纹手臂；眼缝少量冷玉光。
- 视角：横版正交、轻微三分之四、朝右，后续围绕脚底镜像。
- 可读性：优先面部、肩甲、刀刃和腿间负空间；细纹只服务近看。
- 游戏内目标身体高度：约120–140世界像素；preview.html提供120/140/160px静态对照。

## 交付与边界

master PNG为透明身份原图，尚无动画帧、固定画布/脚底注册或碰撞匹配。
preview.html只是把原图以不同尺寸放在真实场景背景上的静态设计预览，不是引擎截图。
原图、完整提示词保留在同一目录；未替换运行时文件，未提交代码。

先确认代表样板，再制作待机、左右交替移动、蓄力/挥击/收招、受击、死亡的同身份素材。
接入时复用原60Hz战斗时钟、命中窗口、暂停/定格/死亡与资源包原子回退约束。
普通怪扩成不同剪影的刀卒、重甲卒、异化突进怪，应作为后续内容决定，当前首关仍只有grunt/boss。
