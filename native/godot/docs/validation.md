# Godot 首关验证记录

日期：2026-09-27。参照工作区 `NEW_GAME_VALIDATION.md` 记录；该工程是现有游戏的引擎迁移。

## 1. 基本信息

- 游戏：Frontier Brawler，横版带纵深的动作闯关，荒村首关。
- 引擎：Godot 4.7.2，GDScript，GL Compatibility。
- 布局：540×960 竖屏；本轮环境：macOS / Apple M2。
- 目标：先确认桌面单局与原生结构；移动端目标机尚未指定。
- 目标逻辑帧率：60Hz；压力规模：50 单位（1 玩家 + 49 杂兵）。
- 三套图集约 464 KiB；首屏与导出包预算待目标平台确定。

允许继续在该结构上完善首关及准备内容迁移，但不能据此宣称移动端发布达标。

- 自动化通过：双指摇杆+攻击、单指释放不影响其他手指、触摸取消、逻辑坐标换算、
  暂停清空、焦点恢复仍暂停、命中停顿保存按下沿、J/Shift 的 InputMap 映射。
- iOS/Android 真机：无法验证；安全区代码已接入，但未获设备截图。
- 原生窗口真实鼠标/键盘操作：未完成系统级自动操作；本轮 CUA 未识别命令行启动的
  Godot 窗口，不能以引擎级输入测试冒充系统级输入验收。
