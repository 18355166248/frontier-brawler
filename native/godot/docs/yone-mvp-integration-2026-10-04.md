# 四技能最小可玩接入

运行入口仍为 `native/godot/开始游戏.command`，或仓库根目录 `npm run dev:godot`。
本轮新增数字 1–4；WASD、J/K/L/U/I、方向键与原有替代键保留。屏幕下方四个按钮也可点击。
参数是本游戏首关 MVP 配置，并非《英雄联盟》实时数值。所有帧数以 60 Hz 逻辑 tick 计算。

| 按键 | 行为 | 冷却 / 期限 |
| --- | --- | --- |
| 1 蓄风刺击 | 前方线段刺击；每次施放首次命中蓄一层。两层后，下次消耗层数，连续扫掠突进并击飞 | 冷却 0.7s；层数 6s 内未刷新则清空 |
| 2 护盾横扫 | 前方扇形横扫；实际命中后获得护盾，多目标最多 42 点 | 冷却 3.5s；护盾持续 2s |
| 3 灵体出击 | 留下身体锚点并向前离体；再次按 3 或到期回归，按每个目标实际受到的伤害追加 35% 回响 | 冷却 8s；离体最多 5s |
| 4 封命斩 | 18 tick 前摇后扫过直线，移到最远命中目标后方，聚拢并击飞；空放也会位移 | 冷却 12s |

R 使用独立技能规则，不受旧 I 处决的低血门槛限制。Q、W、R 均按施放和目标去重。
W 护盾只吸收后续伤害；不能因持续命中帧无限叠加。E 回归不治疗、不重置冷却、不沿路径伤害。
E 账本使用实际扣血，排除过量伤害；死亡/移除目标不再结算，英雄死亡先清理离体和待结算回响。
跨房间保留四技能冷却，清除锚点、层数、护盾和账本；重启清空所有技能状态和输入。

## 连招及现有规则造成的间隔

主连招：两次 **1 命中**蓄满 → **3** → **1** 第三次突进击飞 → 朝目标方向 **4** → 稍候 **2** → 等敌人落地再 **J** → **3 回归**。
R 施放后需要重新朝聚拢的目标瞄准 W/J；突进或聚拢后，仍需要满足原普攻距离和纵深范围。

原受击后的 20 tick 命中保护仍在（约 0.33s）。R 命中后等待保护结束再输入 W，W 生效时仍能击中浮空目标；
R 第 22 tick 的最早取消点立即输入 W 可能落在保护内，不能称为无缝接招。
原 **J 和 airSlash 都没有 hitsAir**：击飞期间不会造成伤害。R 的浮空持续 36 tick（0.6s），地面 J 要等落地。
Q3 的浮空持续 30 tick（0.5s），**Q3 → L 跳跃 → J 跳劈**可在目标落地后的有效帧命中，不能称为浮空追击。
这些旧规则没有为展示效果而改动；游戏 HUD 显示「稍候接 2 横扫 · J / 跳劈等敌人落地」。

短连招：**J → 1 → J → 2 → K**。需按原取消窗口、受击保护及距离瞄准，并非每帧连按即可无条件命中。
四技能沿用八 tick 按下沿缓冲；前摇、有效帧和恢复/取消点来自新配置。没有计时器或动画回调结算伤害。
暂停和命中定格会冻结冷却、层数、护盾、离体期限、击飞高度与角色动作。

## 表现和改动范围

- `data/yone_mvp.json`：四技能数值和六个逻辑动作；`first_stage.json` 保持原样。
- `scripts/yone_skills.gd`：技能状态、冷却、蓄层、护盾、锚点账本、范围判定及聚拢格位。
- `actor.gd` / `action_state.gd` / `combat.gd`：技能输入、定步长位移/击飞、结算/去重/回响。
- `project.godot` / `input_router.gd` / `main.gd` / `hud.gd`：1–4 按下沿与可点击 HUD、冷却和接招提示。
- `room.gd` / `mistward_room.gd` / `run_controller.gd`：技能边界及跨房间冷却传递。
- `wudu_hero_visual.gd` / `illustrated_actor.gd`：新逻辑动作映射到现有十二动作；旧敌人原画/骨架保持。
- `yone_effects.gd` / `main.tscn`：程序风线、扇形、护盾、身体幽影、离体连线及 R 前摇/聚拢线。

没有新增专属 Q/W/E/R 原画；刺击、突进、横扫、大招复用旧 slash/dash/skill/execute，回归复用 idle。
新逻辑动作切换会清理旧刀光/尘土；移动变速不会影响技能动画速度。
`--illustrated-hero` 仍可回退到原英雄骨架表现，敌人继续原样绘制。
原素材的慢步、手刀/服饰漂移和 slash3 收拔刀过渡限制仍存在，本轮没有手工精修或增加素材动作。
手机实机、多平台导出与性能调优不在本轮验收范围。

## 验证

`npm run validate:godot` 包含原战斗/关卡、姿态、插值、反馈、视口 GUI、素材回退和四技能专门检查。
`tests/yone_mvp_checks.gd` 独立覆盖命中与空放、蓄层/护盾期限及上限、连续扫掠、回响/过量伤害/死亡/移除去重、
R 聚拢/边界、缓冲、键位重复、暂停/定格、重启及跨房间状态，不以旧门禁代替新机制测试。

```bash
godot --headless --path native/godot --script tests/yone_mvp_checks.gd
godot --path native/godot --script tests/yone_mvp_review.gd
```

实际 OpenGL 主场景截图和连招记录输出到被 Git 忽略的 `native/godot/output/yone-mvp/`。
视觉驱动使用高血量敌人、固定 AI 等测试前置条件；仍运行正式输入、动作、碰撞、伤害和击飞。
它忽略测试窗口的焦点暂停并禁用外部 GUI 点按，防止用户切回 Codex 或点击重启破坏样本；正式游戏失焦暂停保持。
截图/离线帧序列验证动作和结算，不代表手动通关或实时性能测试。
